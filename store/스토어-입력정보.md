## 2. 기본 스토어 등록정보

### 간단한 설명 (80자 이내)
```
MP3·녹음 파일 자르기, 작은 목소리 크게, 페이드, 보컬 제거까지 한 번에. 무료 오디오 편집기
```

### 자세한 설명 (4000자 이내)
```
녹음 파일이나 음악을 휴대폰에서 바로 편집하세요.
복잡한 프로그램 없이, 손가락으로 구간을 고르고 저장 버튼만 누르면 끝!

■ 주요 기능

✂️ 자르기
· 초록색 손잡이를 끌어서 원하는 구간만 남기거나 지울 수 있어요
· 시작·끝 시간을 0.1초 단위로 정확하게 입력
· 실행 취소·다시 실행 지원

🔊 볼륨 증폭 (작은 목소리 크게)
· "음성 크게" 한 번으로 작게 녹음된 목소리를 알맞은 크기로
· 최대치 맞춤(노멀라이즈)으로 전체 음량을 최대한 키우기
· 클리핑 방지 리미터로 소리가 찢어지지 않게

🎚️ 페이드 인 / 페이드 아웃
· 시작과 끝을 부드럽게 (0.5초~10초)

🎤 보컬 제거
· 가운데에서 나오는 목소리를 줄여 반주(MR)처럼 만들기
· 저음(베이스·드럼)은 그대로 유지

🥁 템포(BPM) 찾기
· 노래의 빠르기를 자동으로 분석
· 박자에 맞춰 두드리는 탭 템포

💾 저장
· MP3 (128 / 192 / 320 kbps) 또는 WAV로 저장
· 휴대폰의 문서/AudioEditor 폴더에 저장돼요

■ 이런 분께 추천해요
· 회의·강의·통화 녹음에서 필요한 부분만 잘라 내고 싶을 때
· 작게 녹음된 목소리를 크게 키우고 싶을 때
· 벨소리·알람음을 직접 만들고 싶을 때
· 노래 반주(MR)를 간단히 만들어 보고 싶을 때

■ 지원 형식
MP3, M4A, WAV, OGG, FLAC, AAC 등

■ 개인정보
편집하는 오디오 파일은 휴대폰 안에서만 처리되며, 어디로도 전송되지 않습니다.

※ 이 앱은 무료로 제공되며 광고가 포함되어 있습니다.
```
